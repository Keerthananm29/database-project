# 🎨 Online Art Gallery – DBMS Project

This project is a **Database Management System (DBMS)** based web application for an **Online Art Gallery**. It allows users to explore, search, and purchase artworks, while artists can upload their creations. Admins manage the system through a centralized dashboard.

---

## 📌 Project Overview

An Online Art Gallery platform that allows:
- Customers to browse and purchase art.
- Artists to register and upload artworks.
- Admins to manage users, artworks, and transactions.

The system ensures proper database normalization, entity relationships, and real-time interaction between the frontend and backend using SQL.

---

## 💡 Features

- 👨‍🎨 Artist registration and login
- 🖼️ Upload and manage artworks
- 🔍 Browse and search artworks
- 🛒 Cart and purchase system
- 🧑‍💼 Admin dashboard for managing users and artworks
- 📈 Artwork views, likes, and ratings
- 📦 Order history and purchase records

---

## 🧱 Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP / Python / Node.js *(choose based on your stack)*
- **Database**: MySQL / PostgreSQL / SQLite
- **Tools**: XAMPP / phpMyAdmin *(if using PHP + MySQL)*

---

## 🗃️ Database Design

### Key Tables:
- `Users`: Stores user information (customer/artist/admin)
- `Artworks`: Stores artwork details and image links
- `Orders`: Records purchases and buyer information
- `Categories`: Types of art (e.g., Abstract, Landscape)
- `Ratings`: Feedback and star ratings by users
